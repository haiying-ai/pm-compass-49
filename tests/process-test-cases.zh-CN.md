# 49个过程测试案例

每个案例都使用同一份年夜饭项目作为可重复测试夹具。

## 测试约定

执行后应更新过程状态；通过标准是产出物可追溯、责任人明确、缺口可见。

## TC-4.1 · 制定项目章程（Develop Project Charter）

- 过程编码：`4.1`
- 场景：为2027年家庭年夜饭测试“制定项目章程”：12位家人，预算1200元，除夕19:00开饭。
- 测试重点：把菜单、预算、时间和家庭成员安排整合为一份可执行决定

### 前置条件
- 项目目录已初始化且项目经理为爸爸
- 商业机会和发起人可识别
- 家庭成员和饮食限制已收集

### 输入
- 商业文件；协议；事业环境因素；组织过程资产

### 测试步骤
1. 读取与‘制定项目章程’相关的项目文件和输入。
2. 围绕‘制定项目章程’完成年夜饭专属活动：确认12人、预算1200元、除夕19:00开饭和成功标准，并记录假设。
3. 保存过程输出到 `00-governance/4-1-制定项目章程.md`，并在决策日志记录责任人、日期和下一步。

### 预期输出
- 项目章程；假设日志

### 验收标准
- 最小产出文件 `00-governance/4-1-制定项目章程.md` 存在且内容可追溯
- 责任人和后续行动明确
- 若无法完成，状态为blocked并写明缺口；若豁免，状态为waived并记录批准人

### 失败路径
删除或留空关键输入‘商业文件’，验证制定项目章程状态变为blocked并显示缺口。
